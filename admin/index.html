Korte deel-links

Zonder publiceren zit het hele event (inclusief logo's en beelden) ín de link — die wordt dan duizenden tekens lang. Met een sleutel zet de beheeromgeving het event op de server en is de link kort: …/viewer/?e=TOKEN.

De sleutel blijft in deze browser en komt nooit in een deel-link. Maak hem aan via GitHub → Settings → Developer settings → Fine-grained tokens, met alleen toegang tot deze ene repository.

Geen sleutel? Gebruik dan per event de knop "Config downloaden + uploadpagina" — dan plaats je het bestand handmatig in configs/.

De preview rechts ververst automatisch na elke wijziging.

Opgeslagen events

Nog geen events opgeslagen.

De korte link (?e=TOKEN) is het prettigst om te delen en blijft bij bewerken hetzelfde — daarvoor moet het event gepubliceerd zijn (server heeft na publiceren ongeveer een minuut nodig). De lange link bevat het hele event en werkt zonder server, maar wordt met uploads duizenden tekens lang en kan bij kopiëren/plakken afgekapt raken. Events blijven in deze browser bewaard om ze later te bewerken.
